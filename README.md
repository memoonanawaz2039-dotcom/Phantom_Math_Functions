# Phantom Math Functions

Automated mathematical function visualizations rendered using Python and Manim (v0.21.0).

## 🚀 Features
- **Quadratic Function Visualization:** Animates $f(x) = x^2 - 4$, highlights roots at $x = \pm 2$, and tracks moving tangent lines.
- **Trigonometric Wave Rendering:** Programmatic rendering of mathematical functions on coordinate axes.

## 🎥 Rendering
```bash
manim -pql main.py FunctionGraphScene
